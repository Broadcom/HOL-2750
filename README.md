=== Primary benefits of your lab ===

HOL-2750-01-VCF-L    AgentMinder: Configure, Enforce and Observe Security for AI Agents

In this lab you secure two AI agents with AgentMinder. The HR Onboarding Agent acts on behalf of Jane Smith. The Security Compliance Agent runs on its own. You build the governance for both, run them, break them on purpose and find every decision in the audit dashboards.
